Multivariate Analysis of Variance (MANOVA) in Binder Jet Printing Data¶

This project applies multivariate analysis of variance techniques (MANOVA) to binder jet printing data to identify which of six process parameters and their interactions significantly affect the strength and density of the green parts produced. As this is meant to emulate real laboratory data, the sample size is small (N=60) and the datapoints do not originate from a rational DoE design.

Strictly, as there are no categorical variables in this dataset (i.e. no well-defined groups to analyse variance between), this may better be described as multivariate multiple regression, MMR. The procedure is the same, as the statsmodels package accounts for the lack of categorical variables internally.

MANOVA is applied iteratively to exclude all but the significant terms from the model, an ordinary least squares (OLS) model is then used fit to each dependent variable separately, and the model fit and formulation insights highlighted and visualised.

1 | Import Libraries and Data¶

Libraries for data-handling, statistical modelling, and plotting, and the dataset for this project are imported.

The data contains six process inputs:

  • Binder Saturation Percentage (binder_saturation_pct)
  • Particle Size Volume Median in μm (particle_size_d50_um)
  • Binder Viscosity in cP (binder_viscosity_cp)
  • Print Layer Thickness in μm (layer_thickness_um)
  • Cure Temperature in °C (cute_temp_c)
  • Cure Time in minutes (cure_time_min)

And two outputs:

  • Green Part Strength in mPa (green_strength_mpa)
  • Print Density Percentage (print_density_pct)

2 | Check Correlation between Dependent and Independent Variables¶

2.1 | Dependent Variables¶

Computes and prints the correlation and covariance matrices for the two response variables, green_strength_mpa and print_density_pct, to check whether the two dependent variables are related enough to justify analysing them jointly in a MANOVA.

The covariance matrix is less diagnostic and simply serves to illustrate the direction of any linear relationship between two variables. It is dependent on the scale of each variable and values do not indicate strength of the interaction clearly. The negative value here indicates that as one value increases, the other tends to decrease. The correlation matrix is a scaled version of covariance and provides a standardised measure indicating direction and strength of a linear relationship. Here it shows only a weak negative correlation (r ≈ −0.19) between the two response variables. This is a little on the low side to rationalise using a multivariate method (rule of thumb is 0.3-0.7). Treating the two dependent variables separately may valid, but while MANOVA/MMR may not be necessary, the analysis is unlikely to be harmed by continuing with the multivariate option.

A representation of the correlation of the two output variables is visualised using linear regression. A very low R² value, ≈0.035, reinforces a lack of correlation and covariance.

3 | Multivariate Analysis of Variance (MANOVA)¶

3.1 | Define Variables and MANOVA Experiment¶

Defines a function, run_interative_manova(), which runs a single MANOVA experiment using the statsmodel.multivariate package. The Pillai trace p-value for each term (all independent variables and combinations) is then extracted and the variables and combinations sorted according to p-value.

In order to allow this to run smoothly, lists of dependent, independent, and combinations of variables are first defined manually. This could be improved by automatically generation, but was hard-coded for speed.

def run_iterative_manova(data:pd.DataFrame, dependent_variables:list, independent_variables:list):
    '''
    Runs a single MANOVA experiment.

    Acts as a wrapper for the entire experiment for use in an iterative workflow.

    Returns the formula used and the results in a DataFrame object.
    '''   

    # -------------------   MODEL   -------------------

    # define formula for MANOVA (uses the Patsy package that statsmodels is built on)
    formula = " + ".join(dependent_variables) + " ~ " + " + ".join(independent_variables)

    # apply model
    res = manova.MANOVA.from_formula(formula, data=data)#.fit()


    # ----------   COLLECT AND FORMAT DATA   ----------

    # define empty DataFrame object, and populate 'ivs' column with all IVs and combinations used in the experiment
    df_manova = pd.DataFrame(columns=['ivs','main','Pr > F'])
    keys = res.mv_test().results.keys()

    # add to DataFrame
    df_manova['ivs'] = keys
    
    # populate the 'main' column (indicating whether a main feature or an interaction)
    main_tf = []
    
    for k in keys:
        # check for a ':' in the feature name (indicates interaction term) and append True/False
        if bool(re.search(':', k)) == True:
            main_tf.append(False)
        else:
            main_tf.append(True)

    # add to DataFrame
    df_manova['main'] = main_tf

    # for each feature, access the statistic table and pull out the p-value (here called: 'Pr > F')
    for index, row in df_manova.iterrows():
        stat_table = res.mv_test().results[row['ivs']]['stat']
        p_val = stat_table.loc["Pillai's trace"]["Pr > F"]
        
        # add to DataFrame
        df_manova.loc[index, 'Pr > F'] = p_val

    # sort DataFrame according to p=values so that the highest is first, re-index
    df_manova = df_manova.sort_values('Pr > F', ascending=False, ignore_index=True)


    return df_manova, formula
3.2 | Run Iterative MANOVA Experiment to Remove Insignificant Features¶

Runs MANOVA iteractively, eliminating the least significant term on each loop. The procedure is as follows:

  • Refits MANOVA using run_iterative_manova(), as defined above.
  • Drops the term with the highest p-value above 0.05. Interaction terms are removed based only on that criterion. Main effects are not removed on reaching that threshold until all interactions involving that main effect have been dropped.
  • Prints a statement indicating what has been removed on each iteration.

Once all remaining terms have a p-value above the 0.05 threshold, affording a reduced MANOVA containing only significant terms. The final MANOVA formula and results are then printed.

flag = False        ### monitors if all insignificant variables have been removed
ivs_removed = []    ### monitors which main features have been removed


while flag == False:
    # run MANOVA experiment
    df_man, formula = run_iterative_manova(df, dvs, ivs_comb)

    # split into main features and interactions
    df_man_main = df_man[df_man["main"] == True]
    df_man_interaction = df_man[df_man["main"] == False]


    #######################################
    #   INTERACTIONS
    #######################################

    # remove interaction with worst p value, if any are above 0.05
    if df_man_interaction.iloc[0]['Pr > F'] > 0.05:
        least_significant = df_man_interaction.iloc[0]['ivs']

        # get index of value in 'ivs_comb' list and pop this
        to_pop = ivs_comb.index(least_significant)
        ivs_comb.pop(to_pop)

        # give user feedback
        print(f"{len(ivs_comb)} FEATURES REMAINING: removed interaction {least_significant}")
        
    else:
        # if all interactions meet the threshold of p < 0.05, terminate iterative experiment
        flag = True
        print("-------- Resolved --------\n")


    #######################################
    #   MAIN FEATURES
    #######################################

    # check whether each main feature is present in at least one interaction
    present_in_interactions = []     ### collects all IVs present in the interaction features
    
    # for each interaction, split the two IVs in each interaction and append to 'present_in_interactions'
    for x in ivs_comb:
        if bool(re.search(':', x)) == True:
            x1, x2 = x.split(':')
            present_in_interactions.append(x1)
            present_in_interactions.append(x2)

    # create a dictionary using 'present_in_interactions' to define keys
    # collapses any duplicate values in 'present_in_interactions' into a single key
    present_in_interactions_dict = list(dict.fromkeys(present_in_interactions))

    ivs_copy = deepcopy(ivs)     ### deepcopy variable to break link to original

    # for each main feature present in the interactions, pop this from the list of all main features
    # leaves only those main features present in no interactions
    for iv in present_in_interactions_dict:
        to_pop = ivs_copy.index(iv)
        ivs_copy.pop(to_pop)

    # for each main feature already removed, pop this from the list of all main features too
    # avoids attempts to remove the same feature twice
    for iv in ivs_removed:
        to_pop = ivs_copy.index(iv)
        ivs_copy.pop(to_pop)

    # for any main feature remaining in 'ivs_copy' (:. main features to be removed), remove if insignificant
    for iv in ivs_copy:
        # if main feature p-value above 0.05, get index in 'ivs_comb' and pop
        if df_man_main[df_man_main['ivs'] == iv]['Pr > F'].to_numpy()[0] > 0.05:
            to_pop = ivs_comb.index(iv)
            ivs_comb.pop(to_pop)

            # give user feedback
            print(f"{len(ivs_comb)} FEATURES REMAINING: removed main feature {iv}")

            # monitor main features removed by adding to 'ivs_removed'
            ivs_removed.append(iv)

4 | Model and Visualise Results¶

Defines two plotting functions:

  • plot_main() draws a scatter plot of one feature (main effect or interaction) against a response (green_strength_mpa or print_density_pct).
  • plot_interaction() builds a contour plot over two features by predicting the response from the fitted model when all other terms are given their mean values.

def plot_main(data:pd.DataFrame, feature:str, response:str):
    '''
    Plots a scatter chart of a single main feature against a response.
    '''
    # define chart area
    fig = plt.figure(figsize=(5,4))

    # plot data
    plt.scatter(x=data[feature], y=data[response], alpha=0.7, c=WEB_COLOR)
    
    # annotate
    plt.xlabel(feature)
    plt.ylabel(response)

    # format
    fig.tight_layout()
    

def plot_interaction(data:pd.DataFrame, model, feature1:str, feature2:str, response:str, constant_features:list=[]):
    '''
    Plots a contour plot of two features coloured by the response indicating their interation.
    '''
    # define chart area
    fig = plt.figure(figsize=(5,4))

    # define xlims and ylims
    x1, x2 = data[feature1].min(), data[feature1].max(),
    y1, y2 = data[feature2].min(), data[feature2].max(),

    # create sampling grid (25x25)
    x_range = np.linspace(x1, x2, 25)
    y_range = np.linspace(y1, y2, 25)
    X, Y = np.meshgrid(x_range, y_range)

    # create DataFrame indicating IV values at each sampling point
    grid = pd.DataFrame({
        feature1: X.ravel(),
        feature2: Y.ravel(),
    })

    # get mean values for constant features and add to the 'grid' DataFrame
    for ft in constant_features:
        grid[ft] = data[ft].mean()

    # predict the response at each combination of IV values
    Z = model.predict(grid).values.reshape(X.shape)

    # plot data
    plt.contourf(X, Y, Z, levels=50, cmap="viridis")
    plt.colorbar(label=response)

    # annotate
    plt.xlabel(feature1)
    plt.ylabel(feature2)

    # format
    fig.tight_layout()
4.1 | Green Part Strength¶

An ordinary least squares (OLS) linear regression model for green_strength_mpa is fitted using the final MANOVA formula.

Model Fit¶
  • R² indicates the share of the variation in green part strength accounted for by the model. 0.934 indicates that about 93 % of the variance is explained.
  • F Statistic indicates how the model performs against a model with no predictors. The p-value is more interpretable, with p < 0.05 indicating how likely the fit is no predictor is significant. Our value of p < 0.01 shows at least one predictor has significance.
  • Omnibus and Jacque-Bera test normality of the residuals (leftover errors not explained by the model). Normality is assumed to calculate p-values and confidence intervals for each main effect and interaction, so this ratifies a key assumption used by the MANOVA/MMR analysis. In both cases, a p-value for the test of p < 0.05 indicates a non-normal distribution of residuals. Both values here are around p = 0.25.
  • Skew tests whether the distribution of residuals is lop-sided, with a perfectly symmetrical distribution affording a value of 0. Large positive values indicate large positive errors or under-predictions, and large negative values show the opposite. The value of -0.5 is acceptable, with over ±1 a threshold for concern.
  • Kurtosis tests how heavy the tails of residual distribution are, the frequency of extreme errors. A normal distribution would give a value of 3, so our vallue of 2.69 is acceptable.
  • Durbin-Watson checks for autocorrelation. This is a measure of correlation between a value and the preceeding values. It is included here to check for drift in the variable over time, which could be critical for a case where all experiments had been performed sequentially using the same equipment, for example. Ideal value is 2, so the measured value of 1.812 here is acceptable.
  • Condition Number checks for multicollinearity, predictors that the model struggles to separate into individual effects. However, it also rises when predictors are on different scales, so the high result here is not a concern. For a more robust treatment, each predictor could be centered and scaled to the same range. Ideal values are below 30.
  • The Q-Q Plot is used to determine whether or not a set of data follows a normal distribution. It serves as a visual check and reinforcement of the statistical normality tests above. The data fits well to the regression line, indicating normality, with a negative skew, as expected from the skew test.
Formulation Insights¶

The coefficient values can be plugged into the formula for the MANOVA/MMR model to allow prediction: $$ Green Strength (MPa) = -8.171 + 0.1364(BS) + 0.1030(PS) - 0.1601(BV) - 0.0064(LT) + 0.0095(CT) - 0.0017(BS × PS) + 0.0021(BS × BV) - 0.000811(PS × LT) $$

Where BS = binder saturation in %, PS = particle size D50 in μm, BV = binder viscosity in cP, LT = layer thickness in μm, and CT = cure temperature in °C.


Three main effects have significant effects on green part strength (using p < 0.05 as a test of significance) assuming all other variables have a constant value:

Two interactions also show significant effects on green strength:

  • The interaction between binder saturation and particle size (β = -0.0017 MPa/(%·μm), 95% CI [-0.003, -0.000], p = 0.012) indicates that for every extra 1 μm increase in particle size, the benefit of increasing binder saturation by 1% is reduced by 0.0017 MPa. The effect of finer powders on green part strength is less sensitive to binder saturation, perhaps due to a smaller void volume.
  • The interaction between binder saturation and binder viscosity (β = 0.0021 MPa/(%·cP), 95% CI [0.000, 0.004], p = 0.012) indicates that for every extra 1 cP increase in viscosity, the benefit of increasing binder saturation by 1% is increased by 0.0021 MPa. More viscous binders improve green part strength more with increased saturation.

Effects of the significant interactions are visualised. Scatter plots are used for main effects, and contour plots for interactions.

4.2 | Print Density Model¶

Repeats the same procedure for print_density_pct as green_strength_mpa. Please refer to the text accompanying that model for more in depth explanations.

Model Fit¶
  • R² of 0.937 indicates that about 94 % of the variance is explained.
  • F Statistic p-value is < 0.01, indicating at least one predictor has significance.
  • Omnibus and Jacque-Bera show large p-values of 0.832 and 0.763, respectively, indicating a normal distribution of residuals.
  • Skew of -0.107 is good and indicates only a very slight over-prediction of some values.
  • Kurtosis of 2.587 is close to the ideal of 3, indicating light tails for the residual distribution.
  • Durbin-Watson of 2.227 is close to the ideal of 2, indicating minimal autocorrelation.
  • Condition Number is large, but this is to be expected as predictors are on different scales.
  • The Q-Q Plot data fits relatively well to the regression line, reinforcing strong normality of the residuals.
Formulation Insights¶

The coefficient values can be plugged into the formula for the MANOVA/MMR model to allow prediction: $$ Print Density (\%) = 102.2169 - 0.0228(BS) - 0.5728(PS) + 0.4211(BV) - 0.2056(LT) - 0.0311(CT) - 0.0019(BS × PS) - 0.0060(BS × BV) + 0.0031(PS × LT) $$

Where BS = binder saturation in %, PS = particle size D50 in μm, BV = binder viscosity in cP, LT = layer thickness in μm, and CT = cure temperature in °C.

Two interactions also show significant effects on green strength:

  • The interaction between particle size and layer thickness (β = 0.0031 %/(μm·μm), 95% CI [0.001, 0.005], p = 0.002) indicates that for every extra 1 μm increase in layer thickness, the benefit of increasing particle size by 1 μm is increased by 0.0031 %. Thicker layers may permit larger particles to pack more densely.
  • The interaction between binder saturation and binder viscosity (β = -0.0060 %/(%·cP), 95% CI [-0.012, 0.000], p = 0.061) indicates that for every extra 1 cP increase in viscosity, the benefit of increasing binder saturation by 1% is decreased by 0.0060 %. Print density with more viscous binders is reduced with increased saturation, perhaps because more viscous binders introduce greater spacing between particles. This effect is marginally signficant.
